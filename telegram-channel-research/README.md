# Проверенный список Telegram-каналов

Итоговый набор содержит только публичные Telegram-каналы, прошедшие проверку через публичный Telegram preview. Группы, чаты, страницы пользователей, неактуальные каналы, каталоги, ГДЗ/решебники, новости и каналы без подтверждённых услуг обучения в итоговый список не включены.

## Основной результат

- `output/all_valid_channels.txt` — 1067 уникальных ссылок без комментариев.
- `output/tutors_high.csv` и `output/tutors_medium.csv` — индивидуальные репетиторы.
- `output/online_schools_high.csv` и `output/online_schools_medium.csv` — онлайн-школы и образовательные проекты.
- `output/review.csv` — 233 принятых канала со статусом ACCEPTABLE и 798 каналов со статусом STALE для отдельного просмотра.
- `output/rejected.csv` — 14073 отклонённые записи, кроме вынесенных в STALE review.

В каждой принятой CSV-записи есть ссылка, username, название, тип, предмет, активность, дата последнего содержательного поста, confidence, краткое доказательство и источники обнаружения.

## Контроль и состояние

- `state.csv` — все 15938 проверенных кандидатов и их итоговые статусы.
- `search_queries.csv` — 908 обработанных поисковых запросов: 907 DONE и 1 BLOCKED.
- `coverage.csv` — покрытие предметов и категорий.
- `checkpoints/` — 11 последовательных batch-файлов; последний содержит 67 записей.
- `work/qc/batch_samples.csv` — 275 каналов, по 25 из каждого batch.
- `work/qc/high_100.csv` — отдельная выборка 100 HIGH.
- `work/qc/online_schools_30.csv` — отдельная выборка 30 онлайн-школ.
- `STATUS.md` — сводная статистика и источники.

Все три QC-файла в финальном запуске содержат только `CORRECT`.

## Публичные контакты владельцев и авторов

- `output/owner_candidates.csv` — 123 публичных контакта, для которых в описании или публикации прямо встречается связь с автором/основателем/владельцем.
- `output/author_candidates.csv` — публичные контакты авторов и преподавателей.
- `output/manager_contacts.csv` — контакты менеджеров, записи, рекламы и сотрудничества.
- `output/channel_contacts.csv` — все 1618 связок «канал → публичный контакт» с доказательством.
- `output/unique_public_contacts.csv` — 977 уникальных публичных handles; файл содержит технические поля Telegram API и имеет права доступа `600`.
- `output/channels_without_public_contact.csv` — 373 канала без явно указанного публичного контакта.
- `output/channels_unavailable.csv` — каналы, которые на момент проверки больше не определялись как публичные broadcast-каналы.

`OWNER_CANDIDATE` не означает раскрытие скрытого владельца: это только публичное текстовое указание на автора/основателя/владельца. Скрытые администраторы и участники не собирались.
